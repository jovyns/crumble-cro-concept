# CRO concept for Crumble

An independent concept by Jovyn: a conversion-rate (CRO) dashboard built from public customer feedback, plus a shopping assistant that suggests one piece of cookware.

**Not an official Crumble site, and not connected to Crumble's systems.** Not affiliated with or endorsed by the brand.

## What's inside

| Part | What it does |
|---|---|
| **Dashboard** | 151 public reviews and comments sorted into topics, mismatches between promises and buyer experience, A/B tests, solutions, a hook bank, a task board, SEO checks, a test calculator and a handbook |
| **Ask AI** | A chat-style product finder: 5 tap questions, then one suggested piece with what real buyers reported. Below it, a recorded run of the live AI version. |

## Notes

- Review text is shortened into summaries. No reviewer names are included.
- This public copy has no AI connected. The live AI agent is available as a demo on request.
